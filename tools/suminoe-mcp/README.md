# スミノエ MCP サーバー

蓄積した出走表・結果・収支・照合レポートと、公式サイトの現在オッズを **Claude から読む**ための
MCP サーバー（stdio、ローカル実行）。

「昨日の観戦を振り返って」「勝負判定の日は本当に堅かった?」「いまのオッズと事前の読みの乖離は?」
といった問いに、対話で答えられるようにするためのもの。

## 方針

- **読み取り専用。** ファイルを書かない。状態も持たない（オッズの60秒キャッシュだけ）
- **賭け金の推奨も、断定的な的中予測もしない。** データを返すだけで、判断は対話の側に置く
- 収支の計算は**アプリの `lib/tally.ts` をそのまま import して使う**。
  別実装を持つとアプリの表示と答えが食い違うため
- 公式サイトへのアクセスは 1.5 秒以上あける（`collect-history.py` と同じ礼儀）

## ツール

| ツール | 入力 | 返すもの |
|---|---|---|
| `suminoe_list_days` | なし | 蓄積された開催日の一覧（出走表・結果・照合レポートの有無つき） |
| `suminoe_get_racecard` | `date`, `raceNo?` | 出走表と事前分析。raceNo 省略で12R要約 |
| `suminoe_get_results` | `date`, `raceNo?` | 着順・決まり手・払戻。raceNo 省略で12R要約 |
| `suminoe_get_tally` | `date` | その日の収支（賭式別・判定別・レース別） |
| `suminoe_get_review` | `date` | 照合レポート（review_YYYYMMDD.md）の全文 |
| `suminoe_get_my_logs` | `date` | 自分の観戦記録（下記の運用が必要） |
| `suminoe_get_odds` | `raceNo`, `date?`, `topN?` | 3連単の現在オッズ。**取得時刻つき** |

## 使い方

リポジトリルートの `.mcp.json` で登録済み。Claude Code を起動すると承認を聞かれる。

```bash
# 手動で起動して確かめる場合（stdio なので入力待ちになる）
cd tools/suminoe-mcp
npm start
```

## 観戦記録の置き場について

記録はブラウザの localStorage にあるため、このサーバーからは直接読めない。
読ませたい日があるときは、アプリの**書き出しタブ**で CSV をコピーし、次の場所に保存する。

```
tools/suminoe-mcp/data/logs/suminoe-log-20260809.csv
```

`suminoe_get_my_logs` は、置かれていなければこの案内を返す。

## オッズについて

- 対応するのは**3連単のみ**（初版）。他の賭式を聞かれたら未対応と答える
- **オッズは刻々と変わる。** 応答には必ず取得時刻が入るので、それを添えて扱うこと
- 発売前・非開催日は取得できない（`null` を返し、理由を添える）
- 同じレースを繰り返し聞かれたときのために60秒だけメモリにキャッシュする

## テスト

```bash
npm test        # 17ケース。ネット接続不要（fixture でパースを検証）
npm run typecheck
```

オッズのパーサは 2026-08-08 12R の実ページを fixture にして検証している。
**`1-5-3` のオッズ 21.8 が、その日の実際の3連単配当 2,180円 と一致する**ことをテストで固定した。
公式サイトのページ構造が変わったらこのテストが落ちる（意図的）。
