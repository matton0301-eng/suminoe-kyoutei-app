## 1. 実行環境

- Windows 11 / PowerShell 7 ネイティブ（WSLなし）
- Python 3.12+（このPCは 3.14.6 — 動作対象に含める）
- `venv` で仮想環境を作成
- 依存: `requests` のみ（dev依存: `pytest`）
- 出力先 `./output/`、キャッシュ `./cache/` を自動生成

### CLI（確定）

```powershell
python main.py                              # 既定: 当日（R2）
python main.py --date 2026-08-09
python main.py --date 2026-08-09 --format md,csv,chat
python main.py --date 2026-08-06 --dry-run  # 動作確認（フィクスチャの日付）
python main.py --local-file .\cache\B260809.TXT --date 2026-08-09  # 手動解凍時
python main.py --max-bets 6                 # 買い目の型の点数上限（既定6）
python main.py --no-cache                   # キャッシュ無効化
```

- `--format` 既定は `md,csv`。`chat` は標準出力へ
- `--dry-run`: 取得〜出力まで全段階を実行するが、出力ファイル名に `_dryrun` を付ける

## 2. データ取得（検証済み事実に基づく）

### 2-1. 一次ソース

- URL組み立て: `https://www1.mbrace.or.jp/od2/B/{YYYYMM}/b{YY}{MM}{DD}.lzh`（検証済み）
- 404時のフォールバック: `dmenu.html` を取得してリンク解決を試みる
- User-Agent を明示。**キャッシュ優先**（`./cache/` に LZH と解凍後 TXT を保存、再実行時は再取得しない）
- **404 が返った場合のメッセージを具体化**:
  「{date} 分はまだ公開されていない可能性があります（当日 5〜6時頃公開）。時間をおいて再実行してください。」

### 2-2. 解凍（R3・優先順確定）

1. `C:\Windows\System32\tar.exe -xf {file}`（bsdtar。**フルパス必須** — Git Bash の GNU tar は LZH 非対応）
2. `7z.exe`（PATH または `C:\Program Files\7-Zip\`）
3. `lhafile` パッケージ（インストールされている場合のみ）
4. 全滅時: **明確なエラーメッセージ**で (a) 7-Zip の導入、(b) 手動解凍して `--local-file` で渡す手順、の両方を案内して終了。例外を握りつぶさない

### 2-3. 文字コード

- `cp932` でデコード。失敗時は `errors='replace'` で継続し、該当行を警告ログへ
- 標準出力は UTF-8 に reconfigure（R8）

## 3. パース仕様

**桁位置は `docs/03-bangumihyou-format.md` §6 の確定表に従う（R4）。**

- `12BBGN`〜`12BEND` を切り出し（住之江=場コード12）。**行が存在しない場合は「本日は住之江の開催なし」と明示して終了**
- レースヘッダは正規表現（03 §5）: レース番号・レース名・距離・電話投票締切
- 選手行（79バイト固定・6艇×12R）: 艇番/登番/選手名/年齢/支部/体重/級別/全国勝率/全国2率/当地勝率/当地2率/M番号/M2率/B番号/B2率/今節成績(生文字列)/早見
- 選手名の全角スペースは正規化（`岩井　繁` → `岩井繁`）。表示時は元のままでもよいがCSVでは正規化必須
- 数値は `strip()` 後に変換。変換失敗はそのレースを「取得失敗」にして継続（全体を止めない）

### 欠損の扱い（R9）

- **当地勝率 0.00 かつ 当地2連対率 0.00 → 「当地データなし」**として別扱い
- スコアリングで欠損を0点扱いにしない。平均に混ぜない
- 当地データなしの艇のイン信頼度・波乱リスク判定は**全国勝率で代替**し、出力に「当地データなし・全国勝率で判定」と明記する

### ユニットテスト（必須・実装時）

`tests/fixtures/B260806.TXT`（実データ同梱済み）から最低5ケース:

1. 標準的な選手行のフルパース
2. 全角スペース入り選手名（`岩井　繁` の行が実在）
3. 当地勝率 0.00 の行（実在）
4. レースヘッダのパース（締切時刻含む）
5. 住之江セクションの切り出し（12R×6艇=72行が取れること）
6. （追加）LZH解凍: `fixtures/b260806.lzh` → TXT が取り出せること

## 4. 分析ロジック

### 4-1. ベースライン（ハードコード・元仕様どおり）

```
コース別1着率(%): 1C 56.2 / 2C 15.2 / 3C 13.1 / 4C 10.7 / 5C 3.5 / 6C 1.8
1コース決まり手: 逃げ 95.8%
枠なり進入率: 1枠→1C 100.0 / 2枠 94.1 / 3枠 91.8 / 4枠 87.2 (%)
※ 出典: 住之江公式「水面特性」集計期間 2026/5/1〜7/31
```

枠番=進入コースとして扱う。

### 4-2. レースごとの4指標（元仕様どおり。全て「3段階評価+根拠数値」のセット）

**① イン信頼度**（1号艇の 級別/当地勝率/全国勝率/M2率/今節成績）
- 高: A1級かつ当地勝率6.00以上、またはM2率が節内上位（中央値+15pt以上）
- 中: 届かないが当地勝率5.00以上
- 低: B級、当地勝率5.00未満、または当地データなし

**② 波乱リスク**（3・4号艇 vs 1号艇）
- 高: 3or4号艇の当地勝率が1号艇超、またはA1級が3〜6枠にいて1号艇がB級
- 中: 当地勝率差が0.50以内
- 低: 1号艇が明確に上位

※ 当地データなしの艇が絡む比較は全国勝率で代替（R9）

**③ モーター注目艇**: 当日72艇のM2率**中央値+15pt以上**を列挙。該当なしは「該当なし」と明示

**④ 総合判定**
- 勝負: イン信頼度=高 かつ 波乱リスク=低
- 見送り: イン信頼度=低 かつ 波乱リスク=高
- 標準: それ以外

**判定根拠を必ず1文添える**（例:「1号艇が当地6.42のA1級、3・4号艇はB1で差1.2以上のため。」）

### 4-3. 買い目の型（テンプレート提示のみ・断定禁止）

- 勝負 → 3連単フォーメーション 1着固定/2着2艇/3着3艇（6点）
- 標準 → 3連単 1着2艇流し（縮小）+3連複1点
- 見送り → 買わない、または複勝1点
- `--max-bets`（既定6）で点数上限を制御

### 4-4. しきい値の妥当性検証（実装時の必須ステップ）

8/6 フィクスチャで全12R を試算し、勝負/標準/見送りの分布を確認する。
全レースが同じ判定に偏る場合はしきい値を調整し、調整結果を README に記録する。

## 5. 出力

`./output/suminoe_YYYYMMDD.md` / `.csv`、`--format chat` で標準出力。

### 5-1. Markdown（人が読む用・元仕様のフォーマット踏襲）

- 先頭にサマリー: 勝負レース / 見送り推奨 / モーター注目（レース-艇番と2連率）
- レースごとに: 総合判定・イン信頼度・波乱リスク、根拠1文、出走表テーブル（枠/選手/級別/全国勝率/当地勝率/当地2率/M2率/今節）、買い目の型
- 各レース表の下に基準値脚注 1行
- **8/9 の12Rは優勝戦の見込み**（第6日・最終日）。優勝戦はメンバーが揃うため注記があると親切

### 5-2. CSV（UTF-8 BOM付き / Excel用）

1行1艇（12R×6艇=72行）+ ヘッダー。分析指標列（イン信頼度/波乱リスク/総合判定/当地データなしフラグ）を含む。

### 5-3. chat 形式

Claude に貼って相談できる圧縮テキスト。1レース2〜3行・全体100行以内。

---

## 6. ログとエラー処理

- 取得/解凍/パース/分析の各段階で進捗を標準出力へ
- パース失敗レースは「取得失敗」として出力に残し、末尾に警告サマリー
- 生テキストは `./cache/` に保存、再実行時はキャッシュ利用（`--no-cache` で無効化）
- 同じデータを何度も取りに行かない
