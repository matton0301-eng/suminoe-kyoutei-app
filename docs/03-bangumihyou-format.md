## 5. レースヘッダ行のパース

固定長ではなく**正規表現でパースする**（全角数字を含む）:

```python
# 全角→半角変換してからマッチさせる方式を推奨
# 例: 「　１Ｒ  予選　　　　          Ｈ１８００ｍ  電話投票締切予定１５：１７ 」
Z2H = str.maketrans('０１２３４５６７８９：', '0123456789:')
RACE_HEADER = re.compile(
    r'^\s*(\d{1,2})R\s+(.+?)\s+H?(\d{3,4})m\s+電話投票締切予定(\d{1,2}:\d{2})'
)
# 適用前に line.translate(Z2H) し、レース名部分の全角スペースは正規化する
```

抽出できる項目: レース番号 / レース名（予選・優勝戦等） / 距離(m) / 締切時刻。

## 7. 今節成績の注意

- 12バイト領域。ヘッダの「１２３４５６」から **1日=2バイト×6日分** と推定される
  （例: 第3日時点の `6 64` = 1日目1走「6着」、2日目2走「6着・4着」）。
- F（フライング）・L（出遅れ）・欠場等の**記号が入る可能性**があり、厳密なパースは危険。
- **本ツールでは生文字列のまま表示に使う**（着順の羅列として人が読めれば足りる）。
  スコアリングに使う場合も「数字の個数と平均着順」程度の緩い集計に留める。
