## 1. 券種は縦書きの枠から読む（区切り記号は使えない）

**区切り・詰め物の記号は場によって違う。**

- 福岡: `1◆3◆4`、金額は `◆◆◆◆100円`
- 芦屋: `1◆3`、合計は `★★★★1枚券★★★★100円`

さらに**同じ場の中でも、3連単と3連複で同じ記号が使われている**
（福岡の2枚は `1◆2◆3`（3連単）と `1◆3◆4`（3連複）で見分けがつかない）。

したがって:

- **区切り記号から賭式を判定してはいけない**
- 賭式は**数字の左隣にある縦書きの枠**（「3連単」「3連複」「拡連複」「単勝」…）から読む。7択

「拡連複」は3文字なので枠が縦に長い。枠の高さで文字数を絞れる可能性があるが**未確認**。

## 2. 買い方は3つ。券面にラベルが出る

### 通常

買い目がそのまま並ぶ。1行1点。

```
3連複   1◆3◆4  ◆◆◆◆100円
        1. 渡邊 優美
        3. 藤原 菜希
        4. 西橋 奈未
        合計 ◆◆◆1枚 ◆◆◆◆100円
```

### ボックス（「ボックス」と印字）

選んだ艇の全組み合わせ。**組合せ数・各組・合計が出る。**

```
ボックス
3連単   1 山本 兼士
        2 品川 二千翔
        5 中 亮太
        組合せ数 ◆◆6
        各組 ◆◆◆100円
        合計 ◆◆◆◆6枚 ◆◆◆◆600円
```

3艇の3連単ボックス = 6点。公式マークシートの点数表と一致する（`lib/betBuilder.ts`）。

### フォーメーション（「フォーメーション」と印字）

着ごとの候補を並べる。

```
フォーメーション
3連単   1着－45
        2着－45
        3着－126
        組合せ数 ◆◆6
        各組 ◆◆◆100円
        合計 ◆◆◆6枚 ◆◆◆600円
```

展開すると 1着∈{4,5}、2着∈{4,5}、3着∈{1,2,6} で艇の重複を除いて **2×1×3 = 6点**。
券面の組合せ数と一致する。**重複する組合せは1点として数える**（公式カードの注記どおり）。

## 3. 検算に使えるもの

読み取りが正しいかを、**券面の数字だけで確かめられる**。ここが写真取り込みの肝になる。

| 項目 | どの券にあるか | 使い方 |
|---|---|---|
| 合計 ◯枚 | ほぼ全券 | 展開した買い目の点数と一致するか |
| 合計 ◯円 | ほぼ全券 | 各点の金額の合計と一致するか |
| 組合せ数 | ボックス・フォーメーション | 展開した点数と一致するか |
| 各組 | ボックス・フォーメーション | 1点あたりの金額 |
| 選手名 | 通常・ボックス | 艇番と選手名の対応が出走表と合うか |

**合計が合わなければ、読み取りを信用しない。**赤字で出して手で直してもらう。

## 4. 共通して載っている項目

- 場名（ロゴ＋文字）
- 主催（「主催 大阪府都市企業団」など）
- **レース番号**（「12レース」「01レース」）
- **開催日**（「2026年02月23日」）
- 年度・第◯回◯日
- レース名（「ヴィーナスシリーズ第1戦」など）
- バーコードと数字列（払戻機用。**買い目は入っていない前提で扱う**。仕様非公開）

レース番号と開催日が読めるので、**どのレースの記録かを自動で決められる**。

## 5. 未確認のこと

- **場によってレイアウトが違う。** 芦屋の券は他と配置も色も異なる。
  当面は住之江だけを対象にする
- 拡連複など文字数の多い券種で、枠の位置がどれだけずれるか
- 的中券に押される印の有無（払い戻すと券が戻らないため未入手）
- バーコードの内容（仕様非公開。**読まない**）

## 6. 実装方針

1. **通常券から対応する。** 手元にあり、実際に買っている形
2. 「ボックス」「フォーメーション」の文字を見つけたら、
   **読み取らずに「この買い方はまだ未対応です」と出す**。黙って間違えるより良い
3. 券種は枠から読む。区切り記号には依存しない
4. **合計との照合を必ず通す。** 合わなければ登録させない
5. 自動保存はしない。必ず確認画面を挟む
